Contrôle des coordonnées bancaires avant mise en paiement.

Contrôler un IBAN

Saisissez un IBAN. Le module contrôle la validité (MOD 97), extrait les composantes BBAN (25+ pays), tente un lookup banque/BIC, et génère un RIB PDF + QR SEPA.

Astuce : espaces et minuscules sont acceptés. En attente

Le BIC n’est pas codé dans l’IBAN. Le module fait un lookup à partir du code banque via ce JSON local.

Référentiel non chargé.
Format : { "30004": {"name":"…","bic":"…"}, ... }
